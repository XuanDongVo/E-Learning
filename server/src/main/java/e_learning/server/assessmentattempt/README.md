# AssessmentAttempt backend

This package owns the official Assignment runtime and remains separate from ActivitySession.

## Implemented in this branch

- V43 Attempt schema and V44 default migration; V45 changes the Attempt timer column to minutes without editing applied migrations.
- JPA entities, repositories, request/response DTOs and snapshot contract.
- Controller routes:
  - GET /v1/assignments/{assignmentId}/assessment-attempt/intro
  - POST /v1/assignments/{assignmentId}/assessment-attempt
- getIntro validates the active Student, active class and Assignment class target; question count comes from Composition QUESTION items.
- startOrResume uses a get-or-create flow without locking the whole Assignment. Attempt creation runs in a separate transaction; the database unique constraint arbitrates concurrent first-start requests.
- Attempt creation snapshots ordered Composition, settings and question render/grading data; the runtime response only projects the student-safe portion of the question snapshot.
- Deadline is generated by the server from started_at + time_limit_minutes. Resume never resets it.

## Remaining work

- Autosave/revision concurrency/idempotency.
- Submit, timeout auto-submit/finalization, Question Engine grading and result visibility.
- Assignment authoring hard-lock after first Attempt.
- Matching/POOL reference resolution and question-type snapshot characterization tests.
- Backend/frontend build, tests, Flyway validation and browser/E2E verification.

## Session policy

Follow ADR 0027:
- one active same-browser tab via Web Locks with fail-fast conflict;
- stable UUID credential generated by the client and persisted before the first request;
- backend validates the credential and never silently replaces it;
- no heartbeat, stale threshold or automatic takeover in MVP;
- the generic runtime DTO never returns the credential.

## Verification warning

The start/resume slice is not a claim that the complete Student runtime is ready. No current-HEAD compilation/tests, Flyway validation, frontend build or browser/E2E verification has been run.
